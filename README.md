# 🏋️‍♂️ Gym User Management System (Pandas)

Sistema interactivo de consola (CLI) desarrollado en **Python** utilizando **Pandas** para la gestión integral de usuarios de un gimnasio con persistencia de datos en archivos CSV.

---

## 📌 Características Principales

- 🆔 **Asignación Automática de NIP (`gym_nip`):** Generación de identificadores únicos para cada socio.
- 📋 **Operaciones CRUD Completas:**
  - **Altas:** Registro interactivo de usuarios y asignación de membresías.
  - **Consultas & Búsquedas:** Visualización general de datos y filtros por estatus (`ACTIVO` / `INACTIVO`) o coincidencia de nombres.
  - **Modificaciones:** Edición de campos específicos de registros existentes.
  - **Bajas Lógicas:** Cambio de estatus a `INACTIVO` para mantener historial de registros.
- 💾 **Persistencia de Datos:** Procesamiento y actualización en tiempo real sobre `usuarios.csv`.

---

## 🛠️ Tecnologías

- **Lenguaje:** Python 3.x
- **Librería principal:** Pandas
- **Almacenamiento:** CSV (`usuarios.csv`)
